A missão do Bit contra o Ruído

Um vírus chamado Ruído invadiu o computador e a CPU está se apagando. Você é o Bit, o último sinal limpo: atravesse os 5 setores do circuito passando pelos portões lógicos e leve o sinal de reinicialização até o Núcleo da CPU.

  • Você carrega um bit: 0 ou 1. Troque com ESPAÇO, clique ou toque.
  • O circuito tem 3 trilhos. Mude de trilho com ↑ ↓ (ou W S), ou deslizando o dedo.
  • Segure → para acelerar ou ← para ir devagar (ou D A).
  • Cada trilho tem uma porta lógica com entrada fixa: AND 1, OR 0, NOT… Escolha o trilho cuja porta você consegue satisfazer!
  • Saída = PORTA(seu bit, entrada). Saída 1 → passa. Saída 0 → game over. Fuja dos bloqueios ✕.
  • Com dificuldade? Ligue o 💡 (ou tecla H): cada portão mostra qual bit passa.

Primeira vez? Faça o treino guiado (1 minuto).
